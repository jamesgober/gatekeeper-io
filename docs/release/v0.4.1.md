# gatekeeper-io v0.4.1

Released locally 2026-11-09.

A fix: the clearing `Set-Cookie` for a dead session cookie is written once.
Authorization refusals no longer repeat the identity's cookie; it comes only
from `Identified::set_cookie` (or `web_net::Identity::set_cookie`), and only
authentication refusals carry their own. Regression tests in
`tests/sign_in.rs` and the `web` module.
