# gatekeeper-io v0.7.0

Released 2026-11-25.

### Changed

- The `web-net` feature is on web-net 0.11 (serve-net 0.9, HTTP/2).
- When the account or session stores cannot answer, `web::denial` now gives
  web-net's retryable 503 (`Denial::unavailable`) instead of a 403.
- README and API reference reorganised; the API reference has a contents list.

### Migrating from 0.6

- Services using the `web-net` feature move to web-net 0.11 with it. The gate
  API itself did not change.
- Error pages keyed on `gate.unavailable` now see a 503 with
  `DenialKind::Unavailable`, not a 403.
- No session or store changes: existing sessions stay valid.
