# gatekeeper-io v0.4.0

Released locally 2026-11-09.

The `web-net` feature moves to web-net 0.7: `Identified` implements
`Identity::set_cookie`, so web-net writes a cleared session cookie on the
reply, and `web::denial` carries a refusal's cookie with
`Denial::with_cookie`. Breaking only for users of the feature (web-net's
`Denial` is no longer `Copy`). No change to the gates themselves.
